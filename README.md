# ラナキュラ楽曲ソート

ラナキュラの好きな曲を選んでランキングを作る非公式ファンサイトです。「デビルアンセムソート」を参考にしています。

## 起動

親フォルダーの起動.cmd、または親フォルダーで npm start を実行し、http://127.0.0.1:4180 から選べます。Node.js 20.9以上が必要です。画像は同梱済みで起動にnpm installは不要です。

このフォルダーだけの場合は node scripts/serve.mjs で起動し、http://127.0.0.1:4185 を開きます。index.htmlの直接ダブルクリックには対応していません。

## 機能

- 曲名検索、公開年による絞り込み、ランキング対象の選択、自分で曲を追加
- 上位15曲・25曲・全曲・任意の順位数、2曲比較、3～4曲の順番選択
- 途中保存・再開、30回分の戻る操作
- ジャケット入りPNG、結果リンク・テキストのコピー、Xへの共有
- 公式MV・ダンス動画・ライブ映像の表示、未確認曲はYouTube検索
- スマートフォン対応、他グループから独立した保存キー ranaqura-sort:v1

## 曲目と出典

2026-10-08確認、29曲・公式YouTube映像17曲。公式サイトのMUSICリンクからTuneCore全18作品を確認し、Apple Musicの18作品とも照合しました。2026-07-10の「サマー・サマー・サマー！」まで掲載しています。

- [公式サイト](https://www.ranaqura.com/)
- [公式サイト掲載の配信一覧](https://www.tunecore.co.jp/artists?id=756638)
- [Apple Music](https://music.apple.com/jp/artist/1693987643)
- [公式YouTube](https://www.youtube.com/@ranaqura0610)

公式YouTube全50投稿を調べ、採用動画の投稿元、曲名、公開日、尺を確認しています。MV、ダンス動画、ライブ映像の順で優先し、同じ種類では新しいものを使います。OFFICIAL LIVE MUSIC VIDEOはライブ映像と表示します。告知、Shorts、カバー、企画動画、公演全編は曲別リンクに採用していません。

「ラナコレ1」の「えんどれす・しゅみれ〜しょん!」は元のシングル「えんどれす・しみゅれ〜しょん！」にまとめています。YouTubeの「えんどれすしみゅれ〜しょん！」、MY WAYの記号違いも同曲に紐づけています。「まるでワンダーランド！！ (あみ乃)」はラナキュラ名義の配信作品として掲載し、あみ乃の注記も保持しています。「プロローグ」は歌詞付きの楽曲として確認し、収録しています。

同曲の再収録はまとめ、SE・OVERTURE・インスト・カラオケは除外する方針です。リミックス・別言語版は存在する場合に別曲として収録します。日付は確認した作品のうち最も早い発売日で、初披露日とは限りません。未配信・見つからない曲はUIから追加できます。

出典はsongs.jsのsources、ジャケット元URLはartworkSource、映像元URLはvideo.sourceに残しています。コピー用の曲一覧は曲一覧.txt、動画一覧は動画確認一覧.mdです。音源・歌詞は同梱していません。

## 保存と保守

選択・途中結果・追加曲・名前はブラウザ内に保存します。共有リンクのフラグメントに順位・曲名・任意の名前・作成日・対象曲数が入ります。ローカル起動中のリンクは他の端末から開けません。

npm run check、npm testで検証できます。ジャケットを再取得する場合だけ npm ci の後 node scripts/build-jackets.mjs を実行します。データの更新手順は親READMEを参照してください。画像は256px WebPで、PNG出力にも同一オリジンの画像を使います。

単独公開に必要なのは index.html、app.js、engine.js、songs.js、jackets.js、catalog.js、styles.css、favicon.svg、jackets/ です。参考プロジェクトがなくても動作します。

本サイトは非公式で各グループ・関係会社とは関係ありません。
